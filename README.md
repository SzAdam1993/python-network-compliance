# Python Network Compliance

Python-based network operations and configuration compliance system developed as part of a BSc thesis projekct.

## Current functionality

- Central device inventory
- SSH connectivity using Netmiko
- Multi-device processing
- Interface state retrieval
- Authentication and connection error handling

## Lab environment

- Cisco Modeling Labs Free
- Cisco IOL router
- Cisco IOL-L2 switches
- Ubuntu automation server
- Python
- Netmiko

## Planned functionality

- Configuration backup
- VLAN compliance checks
- Interface compliance checks
- Trunk compilance checks
- ACL compilance checks
- Configuration drift detection
- Controlled configuration changes
- Syslog processing
- Reporting

## Security

Credentials are stored separately from the source code and are not committed to the repository.
